# Continuous coastal habitat QA

An isolated development preview, not the completed game. One continuous region and actor, with a narrow safe corridor plus one optional grass branch. Image boundaries do not warp.

Arrow keys/WASD or the direction pad move. A/Z/Enter opens help; B/X/Escape closes it. The normal actor size is 80px; 110px is comparison only. The motion toggle suppresses grass bending without removing occupancy.

The selected background and player art are preserved. Only a narrow authored subset is walkable. Four raised rocks are blocked; small embedded pebbles are decorative. Nearby grass bends after accepted physical movement contacts.

No actual encounters, battle, audio, night, saves, storage or service-worker registration. No whole-region, browser/mobile or iOS approval is implied. This path does not replace the ordinary game or older QA demos. Asset provenance is recorded separately.
