# 거제몬스터 PRE-WORK FREEZE v1

- 날짜: 2026-09-25
- 상태: READY_FOR_WORK_HANDOFF
- 목적: 기존 canonical 파일을 직접 수정하지 않고, Work에서 일괄 동기화할 최신 기준을 고정.

## 핵심 수치
- 생태몬 151종 / 진화 계통 75 / 기술 117개
- 필드 일반 트레이너 84명 (필수 28 / 선택 56)
- 체육관 하급 트레이너 20명 (필수 12 / 선택 8)
- 일반 전투 트레이너 총 104명 (필수 40 / 선택 64)
- 거제볼 총량 12개
- TM 영구 소유 / 무한 재사용

## 반드시 제거·이관할 구형 흔적
구 배지명 3종, 강화 생태리그, 예지 구형 battle ID, 사천왕/윤 박사 POST 무한 재대결,
148~150 포획을 요구하는 온섬의 나침반 조건, 예지 엔딩 이전 No.151 접근 조건,
FINAL_ENDING_RECORD 기반 POST/온라인 해금, full_potion, geoje_ball_probability=1.0,
Save v2 TM quantity/owned 혼합 구조.

## 핵심 구현 원칙
- 기존 cleanup candidate는 보존.
- 기존 정리된 필드 35명을 유지하고 49명을 파생 추가.
- 필드 트레이너 이름은 성 없이 표시.
- 이름/성별은 데이터 생성 시 1회 랜덤 후 고정.
- 서로 다른 지역에서 같은 외형 2~3명 재사용 허용.
- 지역 도감/POST 체크리스트/현재 목표는 가능한 파생 표시.
- 자동저장 백업은 검증된 정상 세이브만 last-known-good를 갱신.
- 연구 의뢰 TM 보상은 기존 고정 획득처와 중복 금지.
- 월드맵/배지 이미지 시안은 canonical이 아님.

상세 규칙은 geoje_prework_freeze_spec_v1.json을 기준으로 한다.
