# Isolated selected-map original World check

This development-only fixture is synthetic assisted QA data, not a user save. It began as a fresh disposable original game session with the QA player label and a level-100 assisted party. Original movement and interaction APIs advanced the original story and then traveled from S8 through S7 to S6. The fixture retains the resulting original grid position and progression; it has no selected-map marker until the visible fresh-QA action explicitly initializes this experimental profile.

This experiment admits only six paired original ports connecting original-grid S6 and native S7, S8 and GYM8. It does not activate trainer battles, shops, or additional events. Original World owns movement, progression and completed saves. Its profile-specific browser storage and explicit export format are separate from ordinary game saves and earlier development profiles. Existing records are not silently upgraded or overwritten by starting fresh QA.

All artwork is reused unchanged from already published project assets. One new transport contains derived S7 collision data, not new artwork: 17,404 exact gzip bytes are represented as canonical base64 text and decoded into the original compressed transport and its exact 7,340,032-byte mask. The mask was produced by decoding the approved original walk-surface mask and applying the unchanged authored feedback geometry. Compressed and raw SHA-256 checks, strict single-member gzip bounds, and exact output hashes prevent silent changes. No image conversion or visual quality change is involved.

This is a bounded comparison experiment, not a production architecture switch or a release-ready game. Headed Chrome testing covers only the explicitly listed controls and observed results. Real tab-focus pause remains unverified in the available browser environment; no synthetic focus events are substituted. Timing includes automation and visible readiness, not physical display paint or a guaranteed frame rate.
