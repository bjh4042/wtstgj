# 생태몬스터: 거제도 — Stage63 + NEW_REBUILD_R2 개발 코드 체크포인트

이 자료는 개발 중 코드 유실을 방지하기 위한 **부분 코드 백업**입니다. 완성 게임, 독립 실행 패키지, 전체 원화 백업 또는 출시본이 아닙니다.

## 포함 범위
- 검증된 Stage63 관리 소스 중 선택된 JavaScript 모듈, 스타일 및 런타임 JSON 데이터의 원본 바이트.
- 포함 파일별 SHA-256과 바이트 수. 복원 무결성 검증은 게임 기능·권리·실기 QA 완료를 뜻하지 않습니다.

## 제외 및 한계
- 이미지·오디오·대용량 환경 바이너리, 미검증 참고자료, 내부 제작/검수 문서 및 비공개 경로를 담은 파일은 포함하지 않습니다.
- 필요한 원화, 기본 프로젝트 파일, 일부 모듈 및 의존성이 빠져 있습니다. 이 체크포인트만으로 설치·빌드·테스트·게임 실행이 가능하다고 주장하지 않습니다.
- 외부 저작물 원본, ROM, 비밀키, 개인정보 및 비공개 참고자료를 공개 범위에 포함하지 않습니다.
- 일부 소스에는 제외된 자산 ID에 대한 기존 비활성 참조가 남아 있을 수 있습니다. 해당 자산의 포함·등장·사용 허가를 뜻하지 않습니다.
- 실제 브라우저·모바일·전체 여정 검수 및 최종 아트 품질 검수 완료를 주장하지 않습니다.
- 이후 새로 재구성한 코드는 원본 Stage63과 구별해 별도로 기록합니다. 이 스냅샷은 Stage80 복원본이 아닙니다.

기존 공개 브랜치 및 배포 상태와 분리된 백업 후보이며, 이 자료 준비만으로 공개 배포나 기존 사용자 저장 변경을 수행하지 않습니다.

## NEW_REBUILD_R1 추가 기록
기존 Stage63 기반으로 새로 재구성한 5개 소스·테스트 파일을 추가 또는 갱신했습니다. 이는 유실된 Stage64~80 원본의 정확 복원이 아닙니다.

범위는 기존 S1 목적지별 leave/release 선택 처리와 최신 세대의 retained-frame 복원 준비입니다. 이 제한된 범위의 실제 브라우저 검증이 수행되었으나 전체 게임·모든 전환·모바일·최종 아트 검수 완료를 뜻하지 않습니다. 원래 라이프사이클 해제 이후 실패까지 완전 롤백된다고 주장하지 않습니다.

원본 검수 로그·스크린샷·내부 작업 메모는 포함하지 않았습니다. 원화와 기본 의존성이 여전히 제외되어 이 저장소 스냅샷만으로 실행할 수 없습니다.

## NEW_REBUILD_R2 — 부분 기능 검증 / PERFORMANCE_HOLD
원래 S1 하린 대결과 GYM1 네이티브 동선·엄격한 저장 검증에 관한 새 재구성 코드·테스트·원본 안전영역 JSON 데이터를 포함합니다. 원본 유실 코드의 정확 복원은 아닙니다.

현재 실제 브라우저 검증은 **부분 기능 PASS**이며 **PERFORMANCE_HOLD** 상태입니다. GYM 귀환 여정 검증은 미완료입니다. GYM2 자료는 휴면 상태이고 S2 경로 통합을 완료했다고 주장하지 않습니다. 테스트 통과나 코드 백업을 전체 여정·성능·모바일·최종 출시 검수 완료로 해석하면 안 됩니다.

이 추가분에서도 이미지·환경 바이너리·실제 QA 원본 로그/스크린샷·사용자 데이터는 제외했습니다. 따라서 체크포인트는 여전히 독립 실행 불가이며 공개 게임 배포가 아닙니다.
